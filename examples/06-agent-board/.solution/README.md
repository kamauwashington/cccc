# Solution

The finished versions of the four files the agents produce:

- `src/schema/messages.ts`
- `src/routes/messages.ts`
- `openapi/messages.openapi.json`
- `REVIEW.md`

Copy them in when a live run stalls:

```bash
npm run solution -- 06
```

Then keep talking and move on. Run `npm run reset -- 06` to go back to the
starting state.

The rest of `src/` is here too, unchanged, so the copy is one command and never
half applied.
