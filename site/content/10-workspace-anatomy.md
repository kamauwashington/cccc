`template/` sits outside `examples/` on purpose, so the npm workspace glob does
not pick it up. Copy from it so the workspaces do not drift.

## The skeleton

| Path | Purpose |
| --- | --- |
| `package.json` | Workspace name and the `start`, `reset`, `test`, `typecheck` scripts |
| `README.md` | The lesson. This is what the site turns into an example page. |
| `PROMPT.md` | The single prompt, verbatim, nothing else |
| `reset.json` | Manifest read by `scripts/reset.mjs` |
| `tsconfig.json` | Per workspace. No shared base config. |
| `vitest.config.ts` | Per workspace |
| `CLAUDE.md` | Scoped memory for this workspace, at the workspace root |
| `.claude/settings.json` | Committed. Portable. No absolute paths. |
| `.claude/settings.local.json` | Generated by `scripts/setup.mjs`. Gitignored. |
| `.claude/memory/` | Auto memory lands here. Gitignored. |
| `.claude/hooks/complete.mjs` | Stop hook. Verifies, then writes `RESULT.md`. |
| `.claude/hooks/bash-output-guard.mjs` | PreToolUse hook on Bash. Blocks unbounded output. |
| `.claude/commands/start.md` | `/start` resets, then runs the contents of `PROMPT.md` |
| `.claude/commands/reset.md` | `/reset` shells out to the npm script |
| `.pristine/` | Reset snapshot. Created by `scripts/snapshot.mjs`. |
| `.solution/` | The proven fix. Applied by `scripts/solution.mjs`. |

## What each example adds on top

The skeleton is the floor. An example adds only the folder its lesson needs.

## Where CLAUDE.md sits

At the workspace root, alongside `README.md`. Both `./CLAUDE.md` and
`./.claude/CLAUDE.md` load, verified with a probe holding one of each.
`04-progressive` is the exception and keeps both, because its `swap.mjs` owns
the root file for the lean and fat comparison.

## The README shape

Every example README follows the same headings, so a reader can jump straight
to the part they want.

```
## What you will see       Two sentences. What happens on screen, and what it proves.
## How it works            Which file does the work, and how Claude Code finds it.
## The prompt              The one prompt, copied from PROMPT.md.
## What to watch for       The one moment that carries the lesson.
## Running it              How to run it. What can go wrong. The fallback.
## Try next                Two or three variations for someone reading at home.
```

## What breaks

- **A workspace left on the template's placeholder name.** Every copy collides
  and npm refuses to run anything. `scripts/verify.mjs` catches it before the
  confusing npx failure.
- **An absolute path in a committed `settings.json`.** The folder stops being
  copyable. `verify.mjs` fails the build.
- **Anything added to the root `.claude/`.** It loads into every example.
  See [Isolation and leakage](#/isolation).
- **`git init` inside an example.** An embedded git repository makes the parent
  repository stop tracking that folder's contents. No workspace here holds one.
  An example that needs history should read it from a committed file instead.
