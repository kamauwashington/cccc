# Recorded screens

Written by `npm run capture`. Each `<name>.txt` is exactly what the terminal
showed, at 76 columns, with the operator's username, hostname and home path
replaced.

A fence in the markdown tagged `capture:<name>` prefers the file here over the
text written inline, so recording one replaces an approximation with no edit to
the page. Delete a file and the page falls back to the inline version.
